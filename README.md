# TISA Skills — Bộ 53 Skill Marketing & Bán Hàng

Bộ skill dành cho học viên Học Viện TISA dùng với Claude Code.

## Cài đặt (1 lệnh)

```bash
git clone --depth 1 https://github.com/tieusangstudio-hash/tisa-skills /tmp/tisa-skills && cp -r /tmp/tisa-skills/.claude/skills/* ~/.claude/skills/ && rm -rf /tmp/tisa-skills
```

Sau đó **khởi động lại Claude Code** để các skill xuất hiện.
